# 坦克大战 Tank Battle 🎮

一个纯 HTML5 + Canvas + 原生 JavaScript 实现的经典坦克大战游戏，零依赖、单文件，打开即玩。

## 🚀 在线游玩

克隆仓库后直接用浏览器打开 `index.html` 即可，无需任何构建步骤或服务器。

## 🎮 操作方式

| 按键 | 功能 |
|------|------|
| `↑ ↓ ← →` 或 `W A S D` | 移动坦克 |
| `空格` 或 `J` | 开火 |
| `P` | 暂停 / 继续 |
| `R` | 重新开始 |

支持移动端触屏操作（触摸屏幕控制方向，自动开火）。

## 🕹️ 游戏规则

- 消灭本关所有敌方坦克即可进入下一关，关卡无限、难度递增
- 敌方坦克有三种类型：**普通**（200分）、**快速**（300分）、**重型**（3点血量，500分）
- 保护右下角的 ★ 基地，基地被毁即游戏结束
- 地形：🧱 砖墙（可摧毁）、⬜ 钢墙（不可摧毁）、🌊 河流（不可通行）、🌲 树林（可隐藏）
- 定时掉落道具：⭐ 加分、💥 炸弹（全屏清敌）、🛡️ 护盾、➕ 额外生命

## ✨ 特性

- 纯原生实现，无任何外部依赖
- WebAudio 实时合成音效，无需音频文件
- 3 张手工设计的关卡地图循环出现
- 简单 AI：敌人会追击玩家或偷袭基地
- 子弹可对射抵消、半格砖块破坏
